# 헤어 프롬 선택기

뷰티플러스 앱처럼 헤어 스타일과 컬러를 골라서 "여자헤어 중단발 C컬 버건디컬러" 같은 문장을 만들고 바로 복사하는 웹앱입니다.
사이트: https://kmuse996-bot.github.io/hair-picker/

## 쓰는 법
1. 아래 **스타일** 탭에서 머리 모양을 고릅니다 (남성 탭이면 "남자헤어"로 바뀜).
2. **컬러** 탭에서 머리색을 고릅니다.
3. 위쪽 문장을 **복사** 버튼으로 복사합니다. 복사한 문장은 기록에 남습니다.

## 수정하는 법
스타일·컬러 목록은 `index.html` 안의 데이터 배열에 있습니다. 고치고 커밋·푸시하면 1~2분 뒤 사이트에 반영됩니다.
